# RCOA Events

منصة فعاليات جمعية ملاك المطاعم والمقاهي.

## النسخة الحالية
نسخة أولية منشورة للاختبار تشمل:
- ست فعاليات تجريبية: مطعم، مقهى، دورة، رحلة محلية، رحلة دورية، ورحلة صيف الضيافة.
- أسماء تجريبية في بعض الفعاليات، مع إمكانية حجب أو نشر أسماء المشاركين المؤكدين من الإدارة.
- عرض الفعاليات والتسجيل وقائمة الانتظار.
- إدارة التسجيل من المستخدم مع الإلغاء وإعادة التسجيل.
- لوحة إدارة لإضافة وتعديل ونشر وإخفاء الفعاليات وإدارة المسجلين.
- رابط مستقل لكل فعالية مع بيانات Open Graph لمعاينة الرابط في تطبيقات التواصل.
- روابط MyFatoorah اليدوية والتذكير عبر WhatsApp في هذه المرحلة.
- بطاقة «اقترح مناسبة» في نهاية الصفحة ترسل إلى الإدارة فقط.
- شعار الجمعية مستخدم كعلامة تبويب للمتصفح.

> ملاحظة: التخزين في هذه النسخة محلي داخل المتصفح (localStorage). الربط الحقيقي متعدد المستخدمين مع MyFatoorah Webhooks ورسائل WhatsApp الآلية يحتاج Backend وقاعدة بيانات.
