# RCOA Events

منصة فعاليات جمعية ملاك المطاعم والمقاهي.

## النسخة الحالية
نسخة أولية منشورة للاختبار تشمل:
- عرض الفعاليات والتسجيل وقائمة الانتظار.
- إدارة التسجيل من المستخدم.
- لوحة إدارة لإضافة وتعديل الفعاليات وإدارة المسجلين.
- روابط MyFatoorah اليدوية والتذكير عبر WhatsApp في هذه المرحلة.
- التحكم في إظهار أسماء المشاركين للعامة.
- زر اقتراح يرسل إلى بريد الجمعية فقط.
- صفحة مشاركة مستقلة للحدث التجريبي مع بيانات Open Graph لمعاينة الرابط.

> ملاحظة: التخزين في هذه النسخة محلي داخل المتصفح (localStorage). الربط الحقيقي متعدد المستخدمين مع MyFatoorah Webhooks ورسائل WhatsApp الآلية يحتاج Backend وقاعدة بيانات.
